# 💎 VAULT RAIDERS - Real-Time Top-Down Multiplayer Heist

> **A fast-paced, real-time 2D top-down multiplayer party heist game featuring touch joystick controls, Mario-Kart chaos power-ups, and room codes for phone and laptop play.**

Built for the **Handshake AI Multiplayer Game Challenge**.

---

## 👥 Recommended Crew Size
> 🔥 **PRO TIP: Best played with 3 or 4+ players!**
> 1 or 2 players is great for learning the controls, but 3 or 4 players unleashes hilarious tackle fights, banana slips, and rocket chases!

---

## 🎮 The Core Rules
1. **Steer:** Use the virtual touch joystick on phone (or WASD / Arrow keys on laptop) to maneuver your thief around the vault.
2. **Steal:** Walk over the **💎 Master Diamond ($1,000)** or **🪙 Gold Ingots ($300)** to grab them!
3. **Escape:** Carry your loot to the **🚐 Getaway Van** at the top of the map to bank your money!
4. **⚠️ Security Threat:** Avoid the security guard drones and their sweeping flashlight cones. If you get caught, sirens wail, you get busted, and you drop all your loot!
5. **💥 PVP Tackles:** If a rival is escaping with the Diamond, dash into them to knock the diamond loose!

---

## 📦 Mystery Power-Ups (Mario-Kart Chaos)
- 🍌 **Banana Peel:** Drop behind you. If a rival steps on it, they spin 360°, drop their loot, and get stunned!
- 🚀 **Rocket Boost:** 3x supersonic speed! Ram opponents into walls to knock their diamonds loose.
- 🧲 **Loot Magnet:** Fires a magnetic pulse that pulls the Diamond straight into your hands from across the room.
- 💨 **Smoke Bomb:** Deploys a smoke cloud that completely blinds the security guard drones.

---

## 🕹️ Controls
- **On Phone / Tablet:**
  - **Move:** Touch anywhere on the left half of the screen (Floating dynamic touch joystick).
  - **Dash / Tackle:** Green `[ 👟 DASH ]` button.
  - **Use Power-Up:** Purple `[ 📦 ITEM ]` button.
- **On Laptop / PC:**
  - **Move:** `W, A, S, D` or `Arrow Keys`.
  - **Dash / Tackle:** `Spacebar`.
  - **Use Power-Up:** `E` or `F`.

## 🚀 Running Locally
```bash
# 1. Install dependencies
npm install

# 2. Start server
npm start
```
Open [http://localhost:3000](http://localhost:3000) on laptop or `http://<YOUR_LOCAL_IP>:3000` on mobile.
